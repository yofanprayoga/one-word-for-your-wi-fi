Each entrant sends one word that describes their Wi-Fi, aiming to be both the funniest and the most accurate. A judge model compares the words two at a time against a published brief, weighing the on-subject fit, the laugh, the truth of it and the freshness of the angle, and the strongest word takes the reward.

## Run it

```sh
python3 main.py
```
